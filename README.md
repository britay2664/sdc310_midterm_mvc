# SDC310 Midterm MVC Rewrite

This is the Week 3 address list application reorganized into Model, View, and Controller. It uses the existing `sdc310_midterm` database and `addresses` table from the midterm. The ZIP of the original application contained PHP code only, so the database and table are not included here.

## Setup

1. Put this project folder in the web server document root (for local XAMPP, `C:\xampp\htdocs\sdc310_midterm_mvc`).
2. Confirm that the `sdc310_midterm` database and `addresses` table already exist in MySQL.
3. Copy `model/config.example.php` to `model/config.php` and enter your own database password. `config.php` is excluded from Git.
4. Start Apache and MySQL, then open `http://localhost/sdc310_midterm_mvc/address_list.php` for local XAMPP, or the corresponding VCASTLE URL.
5. Test Add, Edit, Update, and Delete against a disposable record. The existing table rows should remain available.

## File responsibilities

- `model/database.php`: connection to MySQL.
- `model/address_db.php`: all SELECT, INSERT, UPDATE, and DELETE queries.
- `controller/address_controller.php`: request actions, form values, and redirects.
- `view/address_list_view.php`: page markup and forms.
- `view/styles.css`: all styling.
- `address_list.php`: the original public URL, which loads the controller.

The expected table columns are `AddressNo`, `First`, `Last`, `Street`, `City`, `State`, and `Zip`. The application assumes `AddressNo` is generated by the database when adding a record, as in the original midterm application.
